# Test Management Platform

A multi-tenant test management platform (requirements, test cases, execution,
defects, traceability, reporting) comparable in capability to Zephyr. See
`blueprint/context/project-overview.md` for the full picture once generated,
or `blueprint/project-plan.md` in the meantime.

## Status

Neither app is scaffolded yet. Planned layout: a `frontend/` Next.js app and a
`backend/` Spring Boot (Maven) app - see `AGENTS.md` for the target commands
once each exists.

## Development workflow

This project uses the [AI Coding Blueprint](blueprint/README.md) - see
`AGENTS.md` for the full agent-facing guide.
